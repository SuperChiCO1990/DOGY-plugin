# 抖记DOGY Plugin

面向 Windows 的本机 Agent 插件，支持抖音、小红书、微信视频号、YouTube、TikTok、B站的视频与图集下载，以及可检索的视频笔记。

## 使用

收到新视频链接后，先展示视频标题、平台、作者、时长、画质与预计大小，然后直接下载并分析，不再显示处理方式选择卡片或等待倒计时。

下载期间反馈进度；完成后本机转录语音，结合抽样画面整理内容、时间点和可复用方法，保存笔记并按内容归入一个宽泛分类，在聊天中讲解视频主要内容、重点结论和实际分析范围。保留原视频、本地预览和文件打开入口。

明确说“仅下载”或“不分析”时只保存原片；只想查看视频信息时仅解析。明确取消则停止后续处理。同批重复消息不会重复下载。

首次分析会准备本机 whisper.cpp 转录组件和模型，之后复用。原视频和音频不发送到分析服务；转录文字与抽样画面交给当前 Agent 理解。分析会记录真实阅读范围、画面时间点和缺口，抽样画面不等于逐帧看完视频。

笔记、语音文字、标签、时间点和方法卡保存在本机统一资料库中，不再每次在视频旁生成 `.md`、`.jsonl` 或音频、抽帧文件。分析结束会清理本任务临时材料，保留原片和已保存的资料。旧笔记可复制导入，原文件保留。

可以用描述找回视频、相关时间点和笔记。命中 Codex / Agent 技术方法时，Agent 会说明来源和验证状态，并询问是否用于当前任务；视频中的方法不会因此自动执行。

## 安装与更新

将 [INSTALL.txt](INSTALL.txt) 全文发给 Codex，或让其他本机 Agent 按 [通用接入说明](INSTALL-MCP.md) 配置 MCP 与技能。软件的“复制给Agent提示词”提供简短请求和说明链接，由 Agent 读取详细步骤。

安装脚本优先使用已验证的本机 DOGY。默认安装时，未找到程序或程序低于 1.2.2，会下载并校验最新正式版本。用户显式指定 `-ExePath` 时尊重该程序位置；共享后台能力检查不通过则提示先更新程序，并保留原接入配置。

插件当前版本为 **1.2.5**，支持 DOGY 程序 **1.2.2** 及以上版本。每批新视频链接使用前，Agent 会检查 DOGY 插件更新并重新读取指令；这是使用时更新，离线或更新失败保留已有工具。更新命令：

```text
codex plugin marketplace upgrade dogy --json
codex plugin add dogy@dogy --json
```

更新插件后运行已安装插件的 `scripts/setup.ps1`，再新建聊天加载新 MCP 工具，调用 `dogy_doctor` 检查接入。旧聊天可以重读纯指令，但不能热加载新增工具；必要时重启客户端。只有实际加载了资料库与分析工具，才表示新视频记忆流程可用。

插件加载、握手和工具列表查询不启动 DOGY 后台；首次实际调用工具时才启动，并由多个聊天共用。运行时在首次调用工具时选择已验证的较新 DOGY，并最多每 6 小时后台检查正式 Release。新版校验 SHA256、大小、版本和运行环境后供下一次连接使用；不降级或替换正在下载的程序。下载任务属于本次 MCP 连接；本机资料库与分析任务可以跨聊天检索或恢复。

1.2.1 及更早版本的软件用户可以通过“检查更新”升级。更新插件并运行安装脚本后，彻底退出并重新打开 Agent 客户端，旧连接才会切换到共享后台。

## YouTube 登录验证

YouTube 要求登录验证时，可以在桌面版的“高级选项”展开“首次设置教程（以 Chrome 为例）”：

1. 在自己的 Chrome 中打开 YouTube 视频页面，并登录 YouTube。
2. 安装 [Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)。
3. 回到 YouTube 视频页面，点击扩展图标，确认顶部显示 `youtube.com`；格式选 **Netscape**，点击 **Export**，保存文件。不要选择 Export All Cookies。
4. 回到 DOGY，点击“选择文件”选中导出的文件，再重新解析。

桌面版只记住文件路径，重启无需重填；文件移动时重新选择，登录会话失效时重新导出，清空路径即可停用。Cookie 文件只在自己的电脑使用，不要发送文件内容或上传。登录验证还可能受网络、账号和视频限制影响，不保证所有视频都能下载。

通过 Agent / MCP 使用时，只需提供本机 Cookie 文件的完整路径，支持的工具使用 `cookie_file`；桌面版记住的路径不会自动带入 MCP。也可以明确选择已登录的本机浏览器，让支持的工具使用 `cookie_browser`。默认不读取浏览器；Chrome / Edge 的系统加密保护可能阻止读取，此时使用本机 Cookie 文件或 Firefox。旧聊天未加载新参数时，重新加载 MCP 或新建聊天后再用。

## 本地预览

支持本机媒体预览的桌面聊天会嵌入原视频或图片，图集按单图展示。电脑文件和目录入口明确标为“电脑打开”，不会作为手机原图入口。普通下载仍不附加额外网络下载链接。

明确要求在手机查看原图时，插件可为本次连接已下载的图片提供逐张 HTTPS 原图预览，不附加额外下载按钮。指定原图通过 Cloudflare 临时转发，电脑须在线，链接约一小时有效；只开放已授权媒体，不开放项目目录。手机是否支持聊天内嵌入取决于客户端，原图预览链接可用于直接打开。

## 保存位置

视频沿用 DOGY 设置的保存目录；内容分类只有 `AI与编程`、`设计与创作`、`知识学习`、`生活`、`娱乐`、`其他` 一层，不建立平台或逐视频子目录。

新安装的资料库和临时分析任务默认位于视频保存目录下的“视频资料库”，首次登记后沿用该位置；旧资料库保留原位置；本机转录模型与组件保存在应用数据目录中。程序记录与启动器位于 `%LOCALAPPDATA%\MediaDownloader\Agent`，自动下载的 EXE 位于 `%LOCALAPPDATA%\MediaDownloader\DOGY`。

- 保留先展示信息、进度反馈、内容讲解、视频笔记、分类归档与本地预览。
- 用户明确要求仅下载或只查看信息时，按要求处理；无需更新 DOGY 程序。

## 插件 1.2.3 更新

- 加载插件、握手和查询工具列表时不启动 DOGY，首次实际使用工具时才启动共享后台。
- 多个聊天继续共用后台，下载、分析和笔记检索方式保持不变。
- 本次只需更新插件并重新运行安装脚本，再彻底退出并重新打开 Agent 客户端；无需更新 DOGY 程序。

## 1.2.2 更新

- 多个聊天通过本机命名管道共用同一 DOGY 后台，减少重复进程和解包。
- 每个连接的下载任务与进度相互隔离，资料库和持久分析任务继续共享。
- 最后一个连接断开且下载结束后，后台空闲 60 秒自动退出。
- 分析工具进程按任务临时运行；没有新增批量分析队列。

## 1.2.1 更新

- YouTube 登录验证支持明确选择本机浏览器，或使用本机 Cookie 文件。
- 桌面版新增 Cookie 文件选择、路径记忆和 Chrome 首次设置教程。
- 改善下载暂停、恢复与异常处理，允许恢复失败后重试。
- 视频检索保留同一视频的多个匹配时间点，避免遗漏相关证据。
- 分析任务心跳延迟时保留仍在运行的任务，完善临时材料清理。
- 加强更新文件校验，修复插件运行记录读取与检查时间损坏处理。
- 默认安装准备 1.2.1 程序；明确指定已有程序时按真实版本报告能力。

## 1.2.0 更新

- 完整转录优先，每页最多 200 条；画面先看最多 32 张时间分布概览，再按关键片段补看。
- 支持按起止时间读取密集画面，保留精读能力，概览不等于逐帧观看。
- 复用已完成笔记和真实覆盖范围，明确重新分析时可强制准备新材料。
- 配套程序支持点击标题栏版本号检查更新，继续保留免安装方式。
- 节省情况取决于视频内容与实际阅读范围，不承诺固定额度比例。

## 1.1.1 更新

- 默认每 1 秒抽帧，明显画面变化处加密至约 0.5 秒，连续完全相同画面去重。
- 保留真实取样时间点、重复次数与抽帧策略，旧任务不改写历史覆盖。
- 更新安装默认准备 1.1.1 引擎；明确指定旧程序时如实提示抽帧策略尚未升级。
- 画面变化检测不等于语义关键点识别，短暂小字仍可能漏检。

## 当前交互

- 新视频链接默认直接下载分析，不弹处理方式卡片或等待倒计时。
- 支持明确要求仅下载、只查看信息或取消。
- 同批任务复用已有进度，保留视频与图片的本地预览。

## 1.1.0 更新

- 本机语音转录与真实时间点抽帧，首次分析准备组件和模型。
- 统一视频资料库、全文检索、方法卡与历史笔记导入。
- 分析任务持久保存，支持取消、断点恢复和任务临时文件清理。
- 根据视频内容进行单层分类，保留原片、电脑预览和本地打开入口。
- 默认安装自动补齐过旧的 DOGY 程序；更新失败保留可运行版本并说明限制。
