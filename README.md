# 抖记DOGY Plugin

面向 Windows 的本机 Agent 插件，支持抖音、小红书、微信视频号、YouTube、TikTok、B站的视频与图集下载，以及可检索的视频笔记。

## 使用

先展示视频标题、平台、作者、时长、画质与预计大小，再选择：

- **仅下载**：保存原视频，反馈下载进度、电脑预览和手机下载链接。
- **下载并分析**：保存原视频，本机转录语音，结合抽样画面整理内容、时间点和可复用方法，再按内容归入一个宽泛分类。

首次分析会准备本机 whisper.cpp 转录组件和模型，之后复用。原视频和音频不发送到分析服务；转录文字与抽样画面交给当前 Agent 理解。分析会记录真实阅读范围、画面时间点和缺口，抽样画面不等于逐帧看完视频。

笔记、语音文字、标签、时间点和方法卡保存在本机统一资料库中，不再每次在视频旁生成 `.md`、`.jsonl` 或音频、抽帧文件。分析结束会清理本任务临时材料，保留原片和已保存的资料。旧笔记可复制导入，原文件保留。

可以用描述找回视频、相关时间点和笔记。命中 Codex / Agent 技术方法时，Agent 会说明来源和验证状态，并询问是否用于当前任务；视频中的方法不会因此自动执行。

## 安装与更新

将 [INSTALL.txt](INSTALL.txt) 全文发给 Codex。插件通过官方插件市场命令安装；其他 Agent 需使用其支持的 MCP/Skill 配置方式。

安装脚本优先使用已验证的本机 DOGY。默认安装时，未找到程序或程序低于 1.1.0，会下载并校验最新正式版本。用户显式指定 `-ExePath` 时尊重该程序位置；若其版本过旧，提示视频记忆功能尚不可用。更新失败时保留已有的可运行程序，准确报告可用功能。

插件和 DOGY 程序本次正式版本均为 **1.1.0**。每批新视频链接使用前，Agent 会检查 DOGY 插件更新并重新读取指令；这是使用时更新，离线或更新失败保留已有工具。更新命令：

```text
codex plugin marketplace upgrade dogy --json
codex plugin add dogy@dogy --json
```

更新插件后运行已安装插件的 `scripts/setup.ps1`，再新建聊天加载新 MCP 工具，调用 `dogy_doctor` 检查接入。旧聊天可以重读纯指令，但不能热加载新增工具；必要时重启客户端。只有实际加载了资料库与分析工具，才表示新视频记忆流程可用。

运行时在新 MCP 连接时选择已验证的较新 DOGY，并最多每 6 小时后台检查正式 Release。新版校验 SHA256、大小、版本和运行环境后供下一次连接使用；不降级或替换正在下载的程序。下载任务与手机分享属于本次 MCP 连接；本机资料库与分析任务可以跨聊天检索或恢复。

## 预览与手机下载

支持本机媒体预览的 Codex 桌面聊天会嵌入原视频或图片，并提供本地打开入口。两种下载模式都会附上手机下载链接；选择前说明 Cloudflare 临时连接、有效期和电脑在线要求。用户明确只存电脑时跳过手机分享。

手机链接约一小时有效，经 Cloudflare 转发原文件，不转码、不压缩。下载期间电脑须在线。视频提供原 MP4 下载链接，图集提供逐图预览与下载链接；iPhone 可用 Safari 保存到“文件”。不支持预览的客户端仍提供真实文件位置和可用下载入口。

## 保存位置

视频沿用 DOGY 设置的保存目录；内容分类只有 `AI与编程`、`设计与创作`、`知识学习`、`生活`、`娱乐`、`其他` 一层，不建立平台或逐视频子目录。

本机资料库、临时分析任务位于 `%LOCALAPPDATA%\MediaDownloader\Library`；本机转录模型与组件保存在应用数据目录中。程序记录与启动器位于 `%LOCALAPPDATA%\MediaDownloader\Agent`，自动下载的 EXE 位于 `%LOCALAPPDATA%\MediaDownloader\DOGY`。

## 1.1.0 更新

- 本机语音转录与真实时间点抽帧，首次分析准备组件和模型。
- 统一视频资料库、全文检索、方法卡与历史笔记导入。
- 分析任务持久保存，支持取消、断点恢复和任务临时文件清理。
- 根据视频内容进行单层分类，保留原片、电脑预览和手机入口。
- 默认安装自动补齐过旧的 DOGY 程序；更新失败保留可运行版本并说明限制。
