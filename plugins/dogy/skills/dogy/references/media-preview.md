# 本地媒体展示与手机原图

下载、分类归档或查找已有视频后，按本文件展示真实媒体；用户要求手机看图时再读取对应手机原图流程。

## 电脑聊天

电脑聊天沿用原始本地嵌入：`![图片或视频说明](绝对文件路径)`，图片和视频均使用工具实际返回的文件路径。“下载分析”归档后使用最终路径。本地文件入口明确标为“电脑打开原视频”或“电脑打开原图”；图集目录只标为“电脑打开原图文件夹”。这些是电脑文件入口，不能称为手机可用的“打开原图”或“打开全部原图”。

普通下载不附加额外网络下载链接，也不自动建立分享连接。图集按确认存在的单图绝对路径嵌入图片；数量较多时分批展示并说明已展示的图片范围，不能只嵌入首张却声称聊天已经展示全部原图。不能把目录链接替代逐图预览。


视频使用 `![视频标题](<真实绝对路径>)` 嵌入，Windows 反斜杠可换为正斜杠，路径不要放入代码块。保留“电脑打开原视频”链接。客户端不支持媒体预览或格式无法播放时如实说明并保留文件入口，不宣称已播放，不为预览再次下载或转换原视频，也不上传或另建远程播放器。

## 手机原图

用户明确要求手机看原图、表示手机点本地入口看不到图片，或在本聊天明确要求后续图集提供手机入口时：

- 复用现有 `dogy_download_link`，传入本次连接已成功下载的图集目录或单张图片的真实绝对路径。图集读取返回 `items`，逐项使用真实 `preview_url`；只给需要查看的原图，不展示 `download_url`，不恢复额外视频下载链接。
- 提供“手机查看第 N 张原图”的 HTTPS 链接；客户端支持并允许远程图片嵌入时也可展示真实 `preview_url`。电脑本地嵌入与手机 HTTPS 原图预览分别标明，不把 Windows 路径、目录或 localhost 地址当成手机入口。
- 开始建立手机预览时简短说明：指定原图会通过 Cloudflare 临时转发，电脑须保持在线，约一小时有效；实际有效期采用返回的 `expires_at`。这会临时启动预览转发进程，过期后退出；不开放整个项目或视频目录。
- 返回错误或缺少 `preview_url` 时说明真实原因，不编造链接。仅当前 MCP 连接登记的成功下载可分享；旧聊天里的图集应回到拥有该次下载的聊天创建预览，不能为获取预览重新下载、注册任意路径或绕过媒体身份校验。未验证手机实际显示之前，只能说预览入口已生成并经 HTTP 检查，不能保证所有手机客户端都能嵌入播放。
